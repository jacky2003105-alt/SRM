# SRM 精算考試中文研讀筆記

從 `index.html` 開始，可直接離線閱讀。以 ASM《Exam SRM Study Manual》第四版的 21 個教學章為主，另對照資料夾所附 2024 年 SOA 樣題、考綱及 Coaching Actuaries 公式表與影片選段。這是中文自學筆記，不是官方教材，也不是當期考試範圍公告。

- 各章是獨立 HTML。章首列出概念與建議優先練習的原題號，概念下有對應習題，未入選的題目集中章末。第 1 章僅 2 題；第 10 章沒有章末題，另連到相關練習。
- 共 486 道章末原題與 1 道章內 Quiz；★ 共 192 題。每題有中文題意、參考解答與解析。部分原選擇題改為直接計算或判斷，保留題號與必要數據。按單題的「隱藏解答」即可練習。
- `practice.html` 是跨章習題索引，`samples.html` 是 2024 年 SOA 1–72 號樣題對照（其中 4 題刪除），`exams.html` 是講義 6 回、210 道模擬題的章節索引。模擬卷仍搭配手邊講義作答。
- `pdf/ch01.pdf` 至 `pdf/ch21.pdf` 可分章閱讀；`pdf/exercises.pdf` 集中全書習題。公式使用隨附 KaTeX，不需連網。
- 章內虛線詞彙可查看定義、跳到相關章節，再用返回按鈕回到原處。手機先點詞彙預覽，再點「前往」。

## GitHub Pages

將**本資料夾內的所有檔案**放在要發布的 repository 根目錄（`index.html`、`.nojekyll`、各 HTML、`assets/`、`pdf/`）。不需放入上一層的掃描講義、影片或製作資料。Commit 並 push 後，在 Settings → Pages 選擇從所用分支的根目錄發布。若原站已設定 Pages，使用相同發布位置即可。所有站內網址採相對路徑，也能部署在子目錄。
